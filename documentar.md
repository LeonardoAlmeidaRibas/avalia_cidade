ReactJS:     Construção da interface e dos componentes do site
JavaScript:  Lógica de programação e comunicação com as APIs

CSS3:        Estilização e aparência do site

Node.js:     Ambiente necessário para executar as ferramentas do projeto
JSON Server: API REST simulada para cadastrar e listar avaliações
API de Localidades do IBGE: Fornecimento de informações sobre os municípios brasileiros
ESLint:      Análise do código para identificar possíveis problemas
